TurboWarp QR input

Read QR text without owning the camera.

jsQR consumes frames from Camera Source, decodes QR code text, and can write the result into Temporary Variables for Scratch-style scripts.

wait for QR code set runtime var qrText to textlast QR text

Blocks

wait for QR code set runtime var

Waits until a QR code is visible and stores the decoded text.

wait for QR code and broadcast

Stores the decoded text and starts a broadcast hat after the write.

last QR text

Reports the most recent decoded QR text.

API capability

Unsandboxed extensions can read `Scratch.vm.runtime.ext_kubohiroyajsqr`.

const text = await jsqr.waitForQrText({signal});
const textOrNull = jsqr.scanFrame(frameSource);

`waitForQrText()` acquires Camera Source, polls frames, releases its lease, and returns the first decoded text.

Setup

Load Camera Source before jsQR. Runtime-variable blocks require the Temporary Variables extension (`lmsTempVars2`). The extension does not upload camera frames.
