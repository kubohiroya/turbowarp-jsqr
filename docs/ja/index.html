jsQR
ブロックAPI準備
English日本語

TurboWarp QR input

名前付きカメラからQRを読む。

jsQRはCamera Sourceのフレームを利用してQRコード文字列を復号します。TMPoseが別カメラを使っている間に、`qr`のような下向き専用カメラを指定できます。

wait for QR code on camera qrlast QR text

ブロック

wait for QR code set runtime var

指定カメラでQRコードが見つかるまで待ち、復号した文字列を保存します。

wait for QR code and broadcast

文字列保存後にbroadcastを開始します。

last QR text

最後に読み取ったQR文字列を返します。

API capability

unsandboxed拡張は`Scratch.vm.runtime.ext_kubohiroyajsqr`を参照できます。

const text = await jsqr.waitForQrText({cameraId: 'qr', signal});
const textOrNull = jsqr.scanFrame(frameSource);

`waitForQrText()`はCamera Sourceの名前付きleaseを取得し、フレームをポーリングして最初の復号文字列を返します。

準備

Camera SourceをjsQRより先に読み込んでください。runtime variableブロックにはTemporary Variables (`lmsTempVars2`) が必要です。カメラフレームはアップロードされません。
